# Формат `.nplan`

Файл сессии: вся работа над случаем в одном месте. Обычный **ZIP**,
переименованный в `.nplan` — открывается любым архиватором.

Служит трём задачам:

- сохранить работу и вернуться к ней позже;
- передать случай коллеге целиком, вместе с правками;
- отдать пару «КТ + маска» на дообучение модели.

---

## Структура

```
nasal-20260826-1405.nplan
├── manifest.json
└── data/
    ├── ct_raw.nrrd            полный КТ после конвертации из DICOM
    ├── roi_ct.nrrd            КТ, обрезанный по области интереса
    ├── roi_mask.nrrd          маска той же области (после правок врача)
    ├── mesh_raw.obj           меш из маски
    ├── mesh_clean.obj         после очистки и децимации
    ├── inner_surface.obj      выделенная слизистая
    ├── zones.json             метки зон по граням
    ├── unfolded.json          UV-координаты развёртки и метрики
    └── finalize_report.json   отчёт этапа выделения
```

Набор зависит от того, докуда дошёл случай: если работа остановилась
на модели, файлов развёртки не будет.

## `manifest.json`

```json
{
  "format": 1,
  "app_version": "2026.08.26",
  "created": "2026-08-26T14:05:11",
  "light": false,
  "skipped": [],
  "entries": {
    "ct_raw":   { "file": "data/ct_raw.nrrd",   "size": 302265329 },
    "roi_ct":   { "file": "data/roi_ct.nrrd",   "size":  53620152 },
    "roi_mask": { "file": "data/roi_mask.nrrd", "size":  26810210 }
  }
}
```

| Поле | Смысл |
|---|---|
| `format` | версия формата, сейчас `1` |
| `app_version` | версия приложения, которым сохранён файл |
| `created` | момент сохранения, ISO 8601 |
| `light` | облегчённый режим: полный КТ не включён |
| `skipped` | ключи, которые не удалось упаковать |
| `entries` | `ключ → { file, size }` |

Порядок ключей в `entries` значения не имеет — при открытии
восстанавливается то, что есть, остальное пропускается.

## Обучающая пара

`roi_ct` и `roi_mask` — то, на чём обучалась модель:

```
roi_ct:   (230, 409, 285)  int16   HU от −1000 до 3095
roi_mask: (230, 409, 285)  uint8   классы {0, 1}
```

Геометрия совпадает воксель в воксель. Маска сохраняется **после
правок врача** кистью и ластиком, а не в том виде, в каком её выдала
модель, — поэтому пары годятся для дообучения.

Извлечь без распаковки всего:

```python
import zipfile, json

with zipfile.ZipFile("nasal-20260826-1405.nplan") as z:
    man = json.loads(z.read("manifest.json"))
    for key in ("roi_ct", "roi_mask"):
        entry = man["entries"].get(key)
        if entry:
            z.extract(entry["file"], "training_pairs/")
```

## Персональные данные

**В заголовках `.nrrd` их нет.** При конвертации из DICOM метаданные
не переносятся — остаётся только геометрия:

```
dimension, encoding, endian, kinds, sizes,
space, space directions, space origin, type
```

Ни ФИО, ни дат, ни идентификаторов исследования. Проверено на реальных
файлах.

**Но КТ остаётся медицинскими данными.**

## Как открыть

В приложении — кнопка загрузки в шапке (стрелка вверх). Восстановятся
все этапы, до которых дошёл случай.

Вручную — распакуйте архиватором, `.nrrd` откроются в 3D Slicer или ITK-SNAP,
`.obj` — в MeshLab или Blender.
